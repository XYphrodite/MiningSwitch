# Mining Switch 3

Приложение для XMRig на ПК MOSCOW_ENJOYER: большая кнопка, значок возле часов, оценка дохода своего воркера и уход за Windows. Требуется установленный mining-fleet-agent, Windows PowerShell 5.1 и .NET Framework.

Запуск: `MiningSwitch.exe`. Окно консоли не появляется. Для запуска сразу возле часов: `MiningSwitch.exe -Tray`. Все файлы из архива должны лежать рядом. На целевом ПК приложение установлено в `C:\Program Files\MiningSwitch`, ярлык находится на рабочем столе и в автозагрузке пользователя. Повторный запуск открывает уже работающее окно. Крестик сворачивает его к часам; «Выход» в меню значка закрывает интерфейс, сохраняя состояние майнинга.

## Доход своего ПК

Показывается **оценка**, а не точный баланс выплат. HashVault ведёт начисления на общий кошелёк сети, а отдельному воркеру сообщает выполненную работу. Приложение выбирает только `moscowenjoyer` из `settings.json`; остальные воркеры не учитываются. Кошелёк и настройки выплат не меняются. Имена воркеров должны быть уникальны для этого ПК. Повторные подключения после перезапуска не удваивают сумму; несколько CPU-подключений помечаются предупреждением.

- За 24 часа: средний хешрейт своего воркера за сутки × 86400 × награда блока / сложность сети, с учётом комиссии пула.
- «Учтено с…»: положительные изменения счётчика хешей своего воркера с первого запуска. Первый опрос только запоминает исходную точку. Каждый прирост переводится в оценку XMR по наблюдаемым параметрам сети.
- Рубли: оценка XMR × текущая котировка XMR/RUB HashVault. В окне видны дата курса и время обновления. Котировки старше двух часов не принимаются. Обновление — каждые пять минут или по кнопке.

Суммы не включают электричество; реальные выплаты зависят от PPLNS и удачи пула. История до первого запуска не восстанавливается. Сброс счётчика пула и пропуски наблюдений могут занизить накопленный результат; при сбросе показывается предупреждение. RUB-оценка накопленного XMR меняется вместе с курсом. История сохраняется в `%LOCALAPPDATA%\MiningSwitch\earnings.json` и резервной копии, привязана к ПК и хешу сочетания кошелька с воркером. Кошелёк и токен в историю не записываются.

## Уход за ПК

- Загрузка CPU, занятая RAM, свободное место C/D обновляются примерно каждые 12 секунд.
- Очистка: сначала «Анализ», затем «Удалить найденное». Только файлы старше семи дней в Temp пользователя, Windows\Temp, D:\Temp и D:\TMP. Новые, изменившиеся после анализа, занятые и недоступные файлы пропускаются. Ссылки и точки подключения не обходятся. Анализ действителен 15 минут. Папки целиком не удаляются.
- «Включить игровой режим» останавливает XMRig и запрещает автоматическое возобновление до ручного включения. Настройки игр не меняются. Агент также настроен ставить майнинг на паузу при Dota 2 / CS2.
- Сбалансированная и производительная схемы питания; исходная схема сохраняется при первом переключении и доступна по кнопке возврата. Высокая производительность не гарантирует рост FPS и может повысить потребление.
- Кнопки настроек хранилища Windows и автозагрузки.

Ручное выключение сохраняется после перезагрузки. Включение запускает майнер и разрешает его автозапуск. Команды внешней консоли управления сетью могут изменить эту политику.

## Подключение и проверка

Настройки агента читаются из `%ProgramFiles%\mining-fleet-agent\appsettings.json`; его API вызывается только через loopback. Токен используется в памяти для локального API и не передаётся пулу. Публичный API HashVault получает адрес уже настроенного кошелька для поиска своего воркера. Отключённый агент отображается как недоступный.

Исходники: `Launcher.cs`, `MiningSwitch.ps1`, `MiningSwitch.Features.ps1`. Launcher — GUI-приложение, запускающее PowerShell с `CreateNoWindow=true`. Проверки расчётов, сохранения истории и очистки — `Test-Features.ps1`; интеграционная проверка WPF — параметр `-SmokeReportPath` основного скрипта. Она только читает статус майнера, доход, ресурсы и анализирует Temp. Сборка выполнялась на целевом ПК, без локальной сборки на компьютере разработчика.

Документация пула: https://hashvault.pro/monero/api

## CPU + GPU и доход всей сети

Общая кнопка и меню значка управляют XMRig (CPU) и lolMiner (GPU). Выключение останавливает оба процесса и отключает их автозапуск/возобновление. Команда остановки второго майнера выполняется даже при ошибке первого; итог проверяется по обоим статусам. При частичном выполнении показывается предупреждение. Игровой режим также выключает оба. Состояние GPU, скорость и температура показаны отдельно.

Верхняя сумма — прогноз CPU + GPU только этого ПК в рублях за сутки, с отдельными составляющими. Нижняя — суточный прогноз всех воркеров двух общих кошельков HashVault и LuckyPool; она включает этот ПК. Пользователь подтвердил, что сеть использует эти два кошелька.

CPU: Monero/HashVault, воркер moscowenjoyer. GPU: Tari C29/LuckyPool, отдельный воркер MOSCOW_ENJOYER. Адрес выплаты сохранён, к логину добавлено имя воркера. История безымянного GPU-воркера не присваивается этому компьютеру. XTM/RUB берётся из CoinGecko (minotari), с проверкой возраста котировки до двух часов.

GPU-оценка использует средний хешрейт воркера за сутки и profit24hPer1Ghs из калькулятора LuckyPool, с его преобразованием единиц; дополнительно вычитается опубликованная комиссия пула как консервативная оценка. Это не точные начисления. Журнал GPU сохраняется отдельно в gpu-share-earnings.json; у CPU и GPU показаны собственные даты начала учёта. Накопление — сумма оценок по наблюдаемым изменениям счётчиков, не история всех выплат.

При недоступности одного источника общая сумма не выдаётся за полный доход: видны доступная часть и сообщение о недостающих данных. Публичные запросы имеют ограничение времени и выполняются независимо от кнопки управления. Встроенный Windows curl запускается без окна и без передачи токена агента.
Суточный прогноз не равен фактическим начислениям за прошедшие сутки: пул усредняет доступную историю нового воркера. Для накопления GPU используются принятые доли работы (суммарная сложность shares) × награда блока / сложность сети с комиссией. Эти единицы не смешиваются с g/s из калькулятора скорости. Первое наблюдение — только исходная точка, без выдуманной предыстории.
